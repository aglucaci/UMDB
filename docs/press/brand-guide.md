# UMDB Press Kit

UMDB stands for Urban Microbiome Database.

This press kit contains the approved public-facing logo files and the core guidance for using them consistently in publications, articles, presentations, repository listings, and event materials.

## Primary Identity

- Preferred name: `UMDB`
- Expanded name: `Urban Microbiome Database`
- Preferred logo: `umdb-logo-light.svg` on light backgrounds, `umdb-logo-dark.svg` on dark ones
- The emblem: a culture dish around a city skyline, with microbes (cocci and a rod) linked like records in a database above it

## Approved Assets

- `umdb-logo-light.svg`, `umdb-logo-dark.svg`: the horizontal logo (emblem, `UMDB`, `Urban Microbiome Database`). Prefer SVG; PNG versions (`.png`, transparent, 1752 x 512) and solid-background PNGs (`-solid.png`) are included for tools that need them.
- `umdb-logo-compact-light.svg`, `umdb-logo-compact-dark.svg`: emblem and `UMDB` only, for headers, badges and other small placements.
- `umdb-mark.svg` (and `umdb-mark-512.png`): the emblem alone, transparent.
- `umdb-icon.svg` (and `umdb-icon-512.png`): the emblem on a white rounded tile, for avatars, app icons and favicons.
- Archive, not for new material: `umdb-logo-primary-horizontal-transparent.png`, `umdb-logo-variant-sheet.png`, `umdb-logo-original-concept.png` (the previous artwork).

The SVG files are generated by `logo/make_logo.py` in the repository; the lettering is drawn as outlines from DejaVu Sans, so no font is needed to display them.

## Color Direction

- Logo teal: `#14A085` (deep teal `#0D7A66`)
- Logo amber: `#F2A33A`
- Ink (text on light backgrounds): `#14212B`
- Website dark palette: navy `#09111B`, panel navy `#101A29`, sky `#73A7FF`, light text `#EDF3FF`, muted text `#98A8C0`

## Usage Guidance

- Use the horizontal logo whenever there is enough horizontal room, in the version that matches the background.
- Keep generous clear space around the lockup. A good minimum is the height of the `U` in `UMDB` on all sides.
- Scale proportionally. Do not stretch, squash, crop, tilt, or recolor the mark.
- Avoid placing the logo on noisy photographic backgrounds unless contrast is clearly preserved.
- Do not add outlines, glows, drop shadows, or substitute fonts.
- Avoid placing the full horizontal lockup at very small sizes. For tiny placements, use the compact logo, the emblem or the icon.

## Attribution

Suggested attribution line:

`UMDB (Urban Microbiome Database), public urban microbiome metadata resource.`

## Notes For Publications And Press

- Refer to the resource as `UMDB` on second reference after introducing the full name once.
- Keep the expanded form as `Urban Microbiome Database`.
- Do not use earlier or informal project names for the public-facing identity.
